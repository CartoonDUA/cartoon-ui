# W10 UI

A Windows 10-inspired interface library for FiveM experiences, built with plain HTML, CSS, and JavaScript.

## Demo

[View the live component library](https://cartoondua.github.io/cartoon-ui/)

## Components

- Buttons, switches, and checkboxes
- Notifications and confirmation dialogs
- List and context menus
- Input dialogs
- Progress indicators and skill checks
- Text UI prompts
- Settings interface

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.
